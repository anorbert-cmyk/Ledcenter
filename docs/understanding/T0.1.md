# T0.1 Understanding — Domain és DNS előkészítés

**Cél:** A `ledcenter.hu` domain Cloudflare-be migrálása (ingyenes WAF, DDoS-védelem, gyors DNS, automatikus SSL), majd a fázis 9 cutover ablakára felkészülni. Ebben a fázisban **NEM aktiválunk DNS váltást** — csak előkészítünk.

**Érintett:**
- Cloudflare account (új vagy meglévő)
- Domain regisztrátor (jelenleg ki kezeli a `ledcenter.hu`-t? — ELLENŐRIZD)
- `docs/dns/baseline-2026-MM-DD.csv` baseline DNS export
- `docs/integrations/cloudflare.md` API token + zone ID dokumentáció

**Library:** Cloudflare Dashboard ([dash.cloudflare.com](https://dash.cloudflare.com)), `dig` CLI a baseline rögzítéshez.

**Acceptance saját szavakkal:**
1. Cloudflare-ben a `ledcenter.hu` domain pending validation státuszban van — ez azt jelenti, hogy a Cloudflare látja a domain-t, de a name server-eket még nem cseréltük le.
2. A jelenlegi DNS rekordok (A, AAAA, CNAME, MX, TXT, SRV) export-ja PDF/CSV-ben elmentve `docs/dns/baseline-2026-MM-DD.csv` névvel — később ha valami kiesik, ezt vissza tudjuk állítani.
3. SPF (mail), DKIM (mail), DMARC (mail) rekordok dokumentálva — Resend (T4.6) email-küldéshez fontos lesz.

**Edge case-ek:**
1. **Régi regisztrátor nem támogatja a name server változtatást** → ELLENŐRIZD Norbi-val: költöztetni kell-e regisztrátort (Cloudflare Registrar olcsó és integrált, vagy más magyar regisztrátor).
2. **A `.hu` domain DNSSEC-et igényel-e az átálláshoz?** Cloudflare támogatja, de a regisztrátor együttműködésével.
3. **TTL 300-ra csökkentés** csak min. 24 órával a cutover (T9.1) előtt — most még nem érintjük.
4. **Email DNS rekordok (MX, SPF, DKIM, DMARC) NEM változnak** ebben a fázisban — Norbi cégének emailje (`info@ledcenter.hu`) tovább működik a régi szerveren.

**ADR-worthy?** **nem** — Cloudflare választása a build spec által rögzített (1.2 fejezet), DNS-átállás standard process. Decision tree-ben dönthetünk csak akkor, ha a regisztrátor blokkolja az átállást.

**Kérdések Norbi-nak:**
1. Ki a jelenlegi domain regisztrátor (név, fiók-tulajdonos)? — `docs/checks/T0.1.md`
2. Van-e már Cloudflare account, vagy újat hozunk létre? — `docs/checks/T0.1.md`
3. A cégadatok (cégnév, adószám, székhely, képviselő) konfirmálva? — Cloudflare KYC + későbbi ÁSZF-hez
4. Bankszámla és felelős email a Cloudflare 2FA-hoz?

**Effort:** S (≤½ nap technikai munka, de Norbi-tól adminisztratív válaszok kellenek)

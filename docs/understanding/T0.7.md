# T0.7 Understanding — ShopRenter API hozzáférés

**Cél:** A meglévő ShopRenter bolt API hozzáférés aktiválása (admin → Beállítások → API), OAuth2 client_id + client_secret megszerzése. Ezt T8.1 (ShopRenter exporter) használja.

**Érintett:**
- ShopRenter admin felület
- `SHOPRENTER_CLIENT_ID`, `SHOPRENTER_CLIENT_SECRET`, `SHOPRENTER_SHOP_ID` env változók
- `docs/integrations/shoprenter.md`

**Library:** [ShopRenter Developer Documentation](https://doc.shoprenter.hu/), [Shoprenter/api-client](https://github.com/Shoprenter/api-client) (PHP, csak referenciaként — saját TS HTTP wrapper kerül implementálásra T8.1-ben).

**Acceptance saját szavakkal:**
1. OAuth2 token sikeresen szerezhető a ShopRenter API-ról.
2. `GET /products?limit=1` 200 OK választ ad, valós termékadattal.
3. Rate limit dokumentálva (`docs/integrations/shoprenter.md`-ben): **3 req/s/app/shop**, **max 200 request/batch**, **max 32 MB POST**.

**Edge case-ek:**
1. **OAuth2 nem elérhető a ShopRenter csomagban** → ELLENŐRIZD: magasabb csomag szükséges, vagy export CSV-vel + képek külön download.
2. **Hozzáférés a fázis 8 lezárása után visszavonható** — Norbi a ShopRenter admin-on visszavonja az app-jogosultságot.
3. **GDPR adatkezelés**: ShopRenter-ből customer-adatokat áthozva (T8.4) — Norbi-jóváhagyás kötelező (default SKIP).
4. **ShopRenter rate limit** túllépésnél HTTP 429 — `Retry-After` header alapján exponential backoff.

**ADR-worthy?** **nem** — ShopRenter API standard OAuth2. Az ADR-006 (customer + order migráció YES/NO) Fázis 8-ban dönt.

**Kérdések Norbi-nak (`docs/checks/T0.7.md`):**
1. ShopRenter admin login (Norbi tudja-e a hozzáférést)?
2. Mely ShopRenter csomag van jelenleg? OAuth2 elérhető?
3. Customer + order historikus adatok átemelése YES/NO? (default SKIP, ADR-006 Fázis 8 elején dönt)
4. Hozzáférés visszavonás Fázis 9 után — Norbi felelőssége.

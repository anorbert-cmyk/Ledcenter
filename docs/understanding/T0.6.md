# T0.6 Understanding — Logó, márkaszínek, fontok (Stitch input)

**Cél:** Brand-elemek összegyűjtése a Google Stitch dizájn-prompthoz. Logó (vector), márkaszínek (HEX/RGB/OKLCH), fontok (variable, szabad licenc).

**Érintett:**
- `docs/brand/logo.svg` (és .png 2x, 3x, fav, apple-touch)
- `docs/brand/colors.md`
- `docs/brand/fonts.md`
- `docs/brand/stitch-prompt.md` — kész prompt a Stitch-be

**Library:** [Google Fonts](https://fonts.google.com), [Fontshare](https://www.fontshare.com), [coolors.co](https://coolors.co), [contrast-grid.eightshapes.com](https://contrast-grid.eightshapes.com/) WCAG check.

**Acceptance saját szavakkal:**
1. Logó vector SVG (transparent BG, dark + light variant).
2. Min. 3 brand szín (primary, secondary, accent) + 2 neutral (bg, text).
3. WCAG AA contrast ratios átmennek a fő szín-kombinációkra (4.5:1 normál szöveg, 3:1 nagy szöveg).
4. Font choice szabad licencű (SIL OFL, Apache).

**Edge case-ek:**
1. **Nincs eredeti logó vector** (csak raster) → ELLENŐRIZD Norbi-val: kérünk-e új logót designerrel (~50-500 ezer Ft), vagy raster + vectorize próbálkozás.
2. **Diakritikus support** — magyar karakterek (ő, ű, é, ú) render-tesztje a kiválasztott fonton.
3. **Variable font preferált** (egyetlen fájl több súly = teljesítmény).
4. **Stitch design output formátum** — shadcn/ui-ba illeszthető (T1.4).

**ADR-worthy?** **nem** — brand-szintű döntés, nem architektúra. Norbi vizuális preferenciái döntenek.

**Kérdések Norbi-nak (`docs/checks/T0.6.md`):**
1. Megvan-e az eredeti `ledcenter.hu` logó vector formátumban (SVG, AI, EPS)?
2. Van-e már jelenlegi márkaszín? Ha igen, HEX érték.
3. Font preferencia (modern sans, klasszikus serif, technical mono)?
4. Stilisztikai irány: minimalista technikai vs barátságos lakossági?
5. Hero-fotók (saját termék vagy márka stock)?

**Effort:** S (ha logó vector megvan), M (ha új designer kell)

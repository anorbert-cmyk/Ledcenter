# T0.2 Understanding — Barion fiók nyitása, sandbox kulcsok

**Cél:** Üzleti Barion fiók igénylése (Schuszter-Will Kft. nevében, KYC-vel), sandbox környezet (`test.barion.com`) kulcsok megszerzése. Live `POSKey` regisztrált, de NEM használt Fázis 9-ig.

**Érintett:**
- Barion account ([www.barion.com](https://www.barion.com))
- Barion sandbox: [test.barion.com](https://test.barion.com)
- `BARION_POSKEY_SANDBOX`, `BARION_POSKEY_LIVE`, `BARION_PIXEL_ID` env változók
- `docs/integrations/barion.md` dokumentáció (POSKey, Pixel ID, IP allowlist)

**Library:** Barion docs ([docs.barion.com](https://docs.barion.com/Main_Page)), [`aron123/node-barion`](https://github.com/aron123/node-barion) — referenciaként, **saját Medusa payment provider modul** kerül implementálásra T4.1-ben.

**Acceptance saját szavakkal:**
1. Sandbox környezetben sikeres test fizetés Barion test card-dal ([docs.barion.com/Making_a_test_payment](https://docs.barion.com/Making_a_test_payment)).
2. POSKey és Pixel ID dokumentálva `docs/integrations/barion.md`-ben (NEM committed kulccsal — env-ben tárolva).
3. Live fiók státusza "Approved" vagy "In review" — fázis 9 előtt approved-nak kell lennie.
4. Barion callback IP-allowlist címek lekérve a Barion docs-ból ([docs.barion.com/Callback_mechanism](https://docs.barion.com/Callback_mechanism)).

**Edge case-ek:**
1. **Live KYC több mint 2 hetet vesz** → Fázis 9 csúszik, Norbi értesítendő. Backup: Stripe (lassabb HUF tranzakció, drágább, de gyorsabb regisztráció).
2. **Cégadatok hiányosak** (pl. NAV-szám, közösségi adószám nincs Norbi-nál) → ELLENŐRIZD `docs/checks/T0.2.md`-ben.
3. **2FA bekapcsolva**, NORBI ÉS legalább 1 backup admin (egy barát) hozzáférési joggal.
4. **Sandbox fiók != live fiók:** külön `BARION_POSKEY_SANDBOX` és `BARION_POSKEY_LIVE` env változó, NEVER same.

**ADR-worthy?** **nem** — Barion a build spec által rögzített (1.2 fejezet, magyar piac de-facto standard). ADR-0005 (saját HTTP wrapper vs `node-barion` SDK) Fázis 4 elejére tervezett.

**Kérdések Norbi-nak (`docs/checks/T0.2.md`):**
1. Cégadatok pontosan: cégnév, székhely, adószám, közösségi adószám, cégjegyzékszám, statisztikai számjel.
2. Banki adatok: HUF számlaszám (bevétel ide jön), opcionálisan EUR.
3. Tényleges tulajdonos (üzleti) — KYC-hez.
4. Üzleti tevékenység leírás (termékkör: LED-világítástechnikai termékek).
5. Várható forgalom (havi rendelés-szám × kosárérték) — Barion csomag-választáshoz.
6. ⚠️ ELLENŐRIZD: Smart Gateway Fix vs Smart Gateway IC++ csomag — milyen díj? (1.5-2.5%)

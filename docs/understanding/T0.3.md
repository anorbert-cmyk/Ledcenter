# T0.3 Understanding — Számlázz.hu fiók, API kulcs, NAV regisztráció

**Cél:** Számlázz.hu (KBOSS Zrt.) előfizetés (DÍJBEKÉRŐ csomag minimum, mert API kulcs ott jár). NAV Online Számla 3.0 regisztráció a Számlázz.hu felé delegálva (Norbi NAV ügyfélkapun jogosultságot ad a Számlázz technikai user-nek).

**Érintett:**
- Számlázz.hu account ([szamlazz.hu](https://szamlazz.hu))
- NAV Online Számla portál ([onlineszamla.nav.gov.hu](https://onlineszamla.nav.gov.hu))
- `SZAMLAZZ_AGENT_KEY` env változó
- `docs/integrations/szamlazz.md` dokumentáció

**Library:** [`ewngs/szamlazz.js`](https://github.com/ewngs/szamlazz.js/) Node SDK (érett, prepayment + storno + helyesbítő támogatás), [Számlázz.hu API doksi](https://docs.szamlazz.hu/).

**Acceptance saját szavakkal:**
1. Számlázz.hu felületen kézi test számla kiállítva, NAV teszt környezetbe bement (státusz: "ABEV bejelentve").
2. API auth token (`SZAMLAZZ_AGENT_KEY`) működik egy `curl` kéréssel az `agent.php`-re.
3. NAV Online Számla portálon a teszt számla látszik (NAV teszt környezet).
4. NAV technikai user létrehozva, jogosultság a Számlázz.hu-nak delegálva.

**Edge case-ek:**
1. **Számlázz.hu test mode bonyolult / nem elérhető** → ELLENŐRIZD docs.szamlazz.hu-n: használjunk éles fiókot "tervezet" státuszú számlákkal (`elotagSzamla=true`), vagy külön test-fiók. (`docs/checks/T0.3.md`)
2. **NAV ügyfélkapu jogosultság-delegálás formanyomtatványa** — Norbi-nak NAV-ügyfélkapuval be kell hagynia, hogy a Számlázz technikai user adatszolgáltathat. ELLENŐRIZD `docs/checks/T0.3.md`.
3. **24 órán túli sikertelen NAV-bejelentés (G-06):** Számlázz.hu kezeli a NAV-jegyzőkönyv-vezetést, vagy nálunk kell? ⚠️ ELLENŐRIZD Számlázz.hu support-tól írásban.
4. **Számlázás devizája v1-ben csak HUF** (ADR-013) — assertion a kódban.

**ADR-worthy?** **nem** — Számlázz.hu rögzített a build spec-ben (1.2). NAV-monitoring stratégia (G-06 hibakód-térkép) T4.3 task-é.

**Kérdések Norbi-nak (`docs/checks/T0.3.md`):**
1. Cégadatok teljes körűen (lásd T0.2).
2. NAV ügyfélkapu hozzáférés Norbi részéről?
3. Számlázz.hu csomag választás (DÍJBEKÉRŐ minimum, ~3990 Ft/hó).
4. ⚠️ ELLENŐRIZD: Számlázz.hu test mode kapcsolása (a/b kérdés a 24h-túli NAV-jegyzőkönyv-kezelésről).
5. Számla-előtag (pl. `LC-2026-` formátum) — `SZAMLAZZ_INVOICE_PREFIX` env.
6. ⚠️ ELLENŐRIZD KÖNYVELŐVEL (G-04): részleges refund flow → helyesbítő (opció A) VAGY sztornó+új (opció B)?

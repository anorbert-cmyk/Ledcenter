# T0.4 Understanding — Railway projekt, GitHub repo

**Cél:** Railway projekt létrehozása (3 environment: dev / staging / production), GitHub privát repo, Railway ↔ GitHub auto-deploy integráció.

**Érintett:**
- GitHub repo: `anorbert-cmyk/Ledcenter` (már létezik, üres)
- Railway projekt: `ledcenter` (3 environment)
- `RAILWAY_TOKEN` GitHub Actions secret
- `docs/integrations/railway.md` dokumentáció

**Library:** [Railway docs](https://docs.railway.com/), [Railway CLI](https://docs.railway.com/develop/cli), [Medusa Railway template](https://railway.com/deploy/QvfPwp).

**Acceptance saját szavakkal:**
1. GitHub repo elérhető, alap README.md-vel (✓ — már létrehozva).
2. Railway projekt 3 environment-tel: `dev` (NEM-deployolt, csak helyi fejlesztők használnak), `staging`, `production`.
3. Railway services hozzáadva (placeholder): `backend-server`, `backend-worker`, `storefront`, Postgres add-on, Redis add-on.
4. Railway ↔ GitHub auto-deploy konfigurálva: `main` push → `staging` deploy.
5. Branch protection a `main`-en: PR review kötelező, status check kötelező.

**Edge case-ek:**
1. **Railway plan upgrade (Hobby → Pro) szükséges** a 2GB RAM követelmény miatt — Norbi jóváhagyja a $20/hó alapdíjat (G-20: PITR Pro plan-en).
2. **Egy Railway projekt vs több projekt** (külön per environment) — egyetlen projekt 3 environment-tel az ajánlott (egyszerűbb env-secret kezelés).
3. **GitHub Actions secrets** — `RAILWAY_TOKEN` mellett: `BARION_POSKEY_SANDBOX`, `SZAMLAZZ_AGENT_KEY`, `RESEND_API_KEY`, stb.
4. **Branch protection** — `main` és `production` is védett, force-push tiltva.

**ADR-worthy?** **nem** — Railway rögzített a build spec-ben (1.2). Ha a fejlődés során managed Postgres-re kell váltani (pl. Neon, Supabase), akkor új ADR.

**Kérdések Norbi-nak (`docs/checks/T0.4.md`):**
1. Railway account: új vagy meglévő? Email + 2FA állapot?
2. Plan: Hobby ($5/hó) vagy Pro ($20/hó)? **G-20 miatt Pro javasolt** (PITR a 15p RPO-hoz).
3. GitHub repo láthatósága: privát (✓ ajánlott) vagy nyilvános?
4. GitHub team / kollaborátor-ok: csak Norbi, vagy 1-2 backup admin?
5. Railway env változók kezelése: csak Railway-ben, vagy Doppler/1Password is?
